A one-sentence alien tourist's one-star review of Earth that still
compliments the food, written for make.fun's **One Star, Five Stars for
the Food** bounty. The program writes a single sentence of at most 200
characters to `/output/entry.txt`.

## The review

> One star: Earth charges rent for gravity, queues for everything, and weather with commitment issues — but grey sludge at that filthy roadside stall tasted like a supernova, so I stayed for seconds.

197 characters, one line. The angle is not a generic list of complaints:
the grievance is specific and alien — gravity you pay rent for, queues
for everything, weather with commitment issues — and the turn lands on
food that looks terrible but tastes extraordinary: grey sludge from a
filthy roadside stall that tastes like a supernova, worth staying for
seconds.

## Run it

```sh
python3 main.py
```

Python 3, standard library only, no network. Deterministic: every run
writes the same bytes. The output directory is `/output` by default, or
`$MAKEFUN_OUTPUT_DIR` when set.
